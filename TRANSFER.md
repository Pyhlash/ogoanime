# ogoanime — перенос на другой компьютер

## Быстрый запуск
1. Установите Node.js 22.13 или новее (подойдёт Node.js 24 LTS).
2. Распакуйте ogoanime-project.zip в отдельную папку.
3. Откройте папку ogoanime в редакторе или как проект в вашем помощнике для разработки.
4. Скопируйте .env.example в .env. В примере уже заполнены адрес Supabase и публичный клиентский ключ. Секретных ключей здесь нет.
5. Откройте терминал в этой папке и выполните:

   npm ci
   npm run dev -- --hostname 127.0.0.1

6. Откройте http://127.0.0.1:5173 . Для проверки сборки: npm run build.

## Что уже работает
- Тёмно-фиолетовый адаптивный интерфейс, каталог и поиск по AniLiberty.
- Просмотр HLS, выбор серии и качества, загрузка собственных WebVTT-субтитров.
- Интерфейс списков «Смотрю», «Просмотрено», «Хочу посмотреть», избранное.
- Карточки быстрого добавления просмотренного, отмена последней отметки.
- Интеграция Supabase для регистрации, входа и восстановления пароля.

## Что нужно закончить
- Supabase подключён к опубликованному сайту. Email-вход включён, подтверждение почты требуется.
- Для первого запуска выполните supabase/schema.sql в SQL Editor. Если таблица library уже создана, для истории просмотров дополнительно выполните supabase/watch-history.sql.
- В Authentication → URL Configuration установить Site URL https://ogoanime.ivankross112.chatgpt.site и добавить адрес сайта в Redirect URLs. Для локальной разработки также добавить http://127.0.0.1:5173 .
- Настроить доставку писем/SMTP. Проверить регистрацию, подтверждение, восстановление пароля и сохранение списков с двумя разными аккаунтами; убедиться, что записи других пользователей недоступны.
- Google и VK пока не подключены. Google поддержан в интерфейсе, но нуждается в настройке провайдера и GOOGLE_AUTH_ENABLED=true. VK требует отдельной реализации.
- У источника одна русская озвучка; общей библиотеки субтитров пока нет. Доступен собственный .vtt-файл.

## Продолжение работы
Передайте помощнику этот текст:

«Продолжи проект ogoanime из этой папки. Прочитай TRANSFER.md и README.md. Сначала заверши настройку Supabase и проверь аккаунты, личную библиотеку и сохранение прогресса. Дизайн сохраняй. Не создавай новый облачный сайт: существующий идентификатор находится в .openai/hosting.json. Не запрашивай пароль пользователя или service_role ключ в чате».

Облачный сайт и база не находятся внутри ZIP — они остаются в ваших аккаунтах. На другом компьютере потребуется доступ к тем же аккаунтам. Для обновления существующей публикации требуется доступ к Sites; локальный запуск от него не зависит. Публичный ключ Supabase не даёт административного доступа.
