# ogoanime

Первая версия сервиса: живой каталог AniLiberty, поиск, плеер HLS, выбор серии и качества, собственные субтитры WebVTT, интерфейс личной библиотеки и карточки просмотренного.

## Подключение аккаунтов

1. Создайте проект на https://supabase.com/dashboard. Не передавайте пароль базы данных или service_role ключ.
2. В SQL Editor выполните `supabase/schema.sql` один раз. Доступ к записям ограничен владельцем через RLS.
3. Добавьте адрес опубликованного сайта в Authentication → URL Configuration: Site URL и Redirect URLs.
4. Укажите SUPABASE_URL и SUPABASE_PUBLISHABLE_KEY в настройках окружения сайта. Это публичный клиентский ключ, не service_role. Локально используйте `.env`.
5. Включите Email/Password, подтверждение почты и настройте отправку писем. Для обычных пользователей требуется собственный SMTP: встроенная отправка Supabase ограничена.
6. Для Google настройте провайдера в Supabase и GOOGLE_AUTH_ENABLED=true. VK пока не подключён: ему нужна отдельная интеграция VK ID.
7. Проверьте два отдельных аккаунта: регистрация, подтверждение, вход, восстановление пароля, отсутствие доступа к чужим записям, сохранение прогресса и списков после перезагрузки.

Без Supabase регистрация и сохранение списков не работают. Интерфейс сообщает об этом, пользовательские данные не подменяются локальным хранилищем.

## Видео

Источник https://api.anilibria.app/api/docs/v1/ . Серии запрашиваются напрямую из браузера, ограничения источника по региону и авторским правам соблюдаются. Не применяется проксирование видеопотока или обход ограничений. Доступность контента зависит от источника. Открытый API сам по себе не означает лицензию на распространение видео.

Сейчас подключена одна русская озвучка AniLiberty. Готовой общей библиотеки субтитров нет: пользователь может открыть собственный файл .vtt в плеере. Другие студии и VK ID не подключены.

## Проверки

TypeScript, сборка Worker, загрузка реального HLS-потока в браузере, поиск на русском, мобильная вёрстка, отказ при некорректном запросе WebMCP. Полный тест аккаунтов и RLS возможен только после подключения проекта Supabase.

## Разработка

Node.js 22.13+; `npm ci`; `npm run dev`; `npm run build`.
